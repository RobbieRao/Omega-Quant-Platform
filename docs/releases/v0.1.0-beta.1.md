# Omega Quant Platform v0.1.0-beta.1

The first public beta unifies research, market data, portfolio and option risk,
backtesting, OMS controls, audit storage, and guarded TigerOpen execution under
the `omega_quant` namespace and `omega-quant` CLI.

## Highlights

- Credential-free deterministic demo with a prebuilt React UI.
- Event-driven core with CTA/backtesting and a documented next-bar fill model.
- Portfolio assessment and optimization, option Greeks and scenario matrix.
- Massive REST/WebSocket integration with explicit host overrides.
- Process-local live arming with token, account, suffix, notional, and risk gates.
- English-default UI with Chinese switching, FastAPI task/SSE support, and LEAN
  sidecar integration.

## Beta limitations

- No real broker order was placed as part of release verification.
- TigerOpen live-order verification remains experimental and requires explicit,
  separate operator authorization.
- This software is not investment advice. Live trading can lose money.
