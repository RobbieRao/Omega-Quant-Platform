# Roadmap

The roadmap describes direction, not a promise of dates or investment results.

## v0.1 beta — safe public foundation

- Credential-free Docker demo and reproducible examples.
- Event core, OMS, CTA/backtest, option risk, portfolio research, React UI.
- Process-local live arming, API authentication, masked broker context.
- CI gates for tests, frontend build, credentials, identity residue and licenses.

## v0.2 — research reliability

- Typed portfolio optimization jobs and export schemas.
- Golden datasets and deterministic cross-engine backtest comparisons.
- Better option-volatility surfaces and multi-underlying scenario analysis.
- Expanded English/Chinese documentation and UI coverage.

## v0.3 — execution observability

- Durable order lineage and reconciliation dashboards.
- Broker-independent execution contracts and another simulated gateway.
- Prometheus/OpenTelemetry health, latency, reject and data-quality metrics.

## Community cadence

Issues are triaged weekly and releases are targeted every two weeks while the
project is in beta. Good-first issues should be small, testable and require no
private credentials.
